# 🚀 Space Dodge
A simple arcade-style game built with Python and Pygame where the player navigates a spaceship to dodge falling meteors!

## Gameplay
- You control a spaceship that can move **left** and **right** using the **arrow keys**.
- Meteors fall from the top of the screen at increasing speeds.
- The goal is to **survive as long as possible** without colliding with any meteors.
- The game ends when your spaceship gets hit.
